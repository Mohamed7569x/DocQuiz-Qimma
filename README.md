**DocsQuiz** is a smart AI-powered platform that helps developers learn and review programming concepts by generating quizzes directly from W3schools a.

**Demo: https://qimma.alsalam-company.com/**

Instead of using fixed or manually written questions, **DocsQuiz** automatically:

* Scrapes trusted learning sources (e.g., W3Schools)
* Stores each topic with its documentation URL
* Summarizes the content and sends it to an AI model
* Generates high-quality quiz questions based on the actual docs

  * Multiple-choice questions
  * Code-output questions
  * Each with explanations and optional hints

Users select their **programming language**, **level**, **topics**, and can optionally add their **name** and **LinkedIn profile**.
DocsQuiz then generates a customized quiz with clean code formatting and an immediate scoring system.

After finishing the quiz, users receive:

* Total score
* Performance breakdown per topic
* Automatically detected weak areas
* Option to retake a focused quiz on weak topics
* A shareable public result page containing their name and LinkedIn link

**DocsQuiz** provides a modern, dynamic, and personalized way to learn programming—without static question banks or manually maintained databases.
